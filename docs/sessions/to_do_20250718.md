#### 1. Análise de Fluxo de Caixa ✅ **CONCLUÍDO**

##### **Conhecimento Fundamental: Foco na Disponibilidade de Liquidez**

**OBJETIVO PRINCIPAL**: Analisar quanto haverá disponível até a data do próximo pagamento

**NECESSIDADE DE PAGAMENTO**:
- **Fonte**: Cronograma JSON (`cronograma_amortizacao`)
- **Cálculo**: % aplicado sobre PL atual (ex: 4% × 100 = 4)
- **Data**: Próxima data do cronograma > hoje

**DISPONIBILIDADE ANALISADA EM 3 CENÁRIOS**:
- **Cenário 1**: Apenas caixa atual
- **Cenário 2**: Caixa + recebimentos previstos
- **Cenário 3**: Caixa + recebimentos conservadores (excluindo inadimplentes)

##### **Análise de Liquidez: Três Cenários**

**💰 CAIXA DISPONÍVEL**
- **Fonte**: Arquivo CSV (dashboard)
- **Cálculo**: Soma das colunas `'caixa'` + `'saldo em aplicações'`
- **Objetivo**: Verificar disponibilidade imediata de recursos

**📅 FLUXOS DE PAGAMENTOS A VENCER**
- **Fonte**: Config JSON (`cronograma_amortizacao`)
- **Cálculo**: % da tabela JSON reflete necessidade financeira
- **Modalidades**: Conforme as duas modalidades acima

**🎯 CENÁRIO 1 - OTIMISTA**
- **Pergunta**: "Hoje a soma do caixa e saldo em aplicações é maior ou igual ao próximo pagamento?"
- **Cálculo**: `Caixa_Disponível >= Próximo_Pagamento`
- **Fontes**: CSV (caixa) + JSON (cronograma) + Modalidade escolhida
- **Output**: Status de cobertura (SIM/NÃO) + gap se aplicável

**🔄 CENÁRIO 2 - PREVISTA (Definido)**
- **Pergunta**: "Considerando os recebimentos previstos até a data do próximo pagamento, haverá liquidez suficiente?"
- **Fonte**: Portfolio XLSX (`valor presente` + `vencimento`)
- **Premissa**: Títulos serão pagos até data de vencimento
- **Filtro**: `data_vencimento <= próximo_pagamento`
- **Cálculo**: `Caixa_Atual + Recebimentos_Previstos >= Próximo_Pagamento`
- **Fluxo**: XLSX → Filtrar títulos → Somar valores → Caixa + Recebimentos → Comparar

**⚠️ CENÁRIO 3 - CONSERVADORA (Definido)**
- **Pergunta**: "Considerando apenas cedentes e sacados sem histórico de atraso, haverá liquidez suficiente?"
- **Base**: Similar ao cenário previsto
- **Diferencial**: Exclui cedentes E sacados com histórico de atraso
- **Premissa**: Se tem ativos atrasados, chance de atrasar os "a vencer" é enorme
- **Filtro duplo**: 1) Excluir cedentes/sacados com dias_atraso > 0, 2) Filtrar por vencimento
- **Cálculo**: `Caixa_Atual + Recebimentos_Conservadores >= Próximo_Pagamento`
- **Dependência**: Campo `dias_atraso` (já enriquecido pelo sistema)
